## The joke

> My manager calls it 'synergy' when he takes credit for my work and 'accountability' when I take the blame for his.

## How it works

`main.ts` (Node 22, no dependencies) writes the one-line joke to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validates the kit gate (1–200 characters,
single line, non-blank), and verifies the written file byte-for-byte, printing
its sha256.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
